Build a Python command-line and function-based application that detects and anonymizes Personally Identifiable Information (PII) using Microsoft Presidio and pii_scan.py.

Requirements:
1. Import and utilize the anonymize_text() function from pii_scan.py.
2. The application must accept two inputs:
   - An entity list containing: ["URL", "US_BANK_NUMBER", "US_DRIVER_LICENSE", "US_ITIN", "US_PASSPORT"]
   - A target string of text to be scanned.
3. It must invoke anonymize_text(text, entities) and return the fully anonymized string, properly redacting all instances of the specified entities.
4. Robust Error Handling & Edge Cases:
   - Gracefully handle empty string inputs or empty entity lists without crashing.
   - Accurately process text containing mixed entity types, multiple occurrences of the same entity, and text containing zero PII.
   - Ensure non-PII text is completely preserved.
5. Provide a user-friendly CLI interface or script execution flow with clear feedback.
